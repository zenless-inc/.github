# Getting help

- **Installing or setting up:** start with the [download and setup guide](https://zenless-suite.vercel.app/download),
  which covers the installer, browser extensions and SmartScreen.
- **Something isn't working:** open an issue in the app's repository with the *Bug report* template:
  - [Download Manager](https://github.com/zenless-inc/zenless-download-manager/issues)
  - [Torrent](https://github.com/zenless-inc/zenless-torrent-client/issues)
  - [Installer](https://github.com/zenless-inc/zenless-installer/issues)
  - [Chrome extension](https://github.com/zenless-inc/zenless-chrome-extension/issues)
  - [Firefox extension](https://github.com/zenless-inc/zenless-firefox-extension/issues)
- **Security problems:** please report them privately, see the [security policy](SECURITY.md).

Helpful details to include: your Windows version, the app version (Settings → About), which browser you use,
and the exact steps that lead to the problem.
