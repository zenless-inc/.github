# zenless-inc/.github

Organization-wide files for [Zenless](https://github.com/zenless-inc):

- [`profile/README.md`](profile/README.md) is the profile shown on [github.com/zenless-inc](https://github.com/zenless-inc).
- The default community health files, which GitHub applies to every repository that doesn't have its own:
  [contributing guide](CONTRIBUTING.md), [code of conduct](CODE_OF_CONDUCT.md), [security policy](SECURITY.md),
  [support](SUPPORT.md), and the [issue templates](.github/ISSUE_TEMPLATE) and [pull request template](.github/PULL_REQUEST_TEMPLATE.md).

Logos in `profile/assets/` come from [zenless-website/brand](https://github.com/zenless-inc/zenless-website/tree/main/brand).
